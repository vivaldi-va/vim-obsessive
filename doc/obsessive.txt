========================================================================
DESCRIPTION                                        *obsessive-description*

Builds upon vim-obsession, centralising session storage.

By default vim-obsession (https://github.com/tpope/vim-obsession) saves a
Session.vim in the current working directory, or a defined directory if provided.

Instead, this addition centralises session storage, using the CWD name. For
example a project under $HOME/example/project/ will create the file:
<dir>/session/project/Session.vim

========================================================================
CONFIGURATION                                        *obsessive-configuration*

There are configuration values available (shown with their default
values):

* set session file storage directory >
  let g:obsessive#dir = '~/.nvim/session'

* configure airline statusline integration >
  let g:obsessive#airline_enabled = 1


========================================================================
USAGE                                               *obsessive* *:Obsess*

:Obsess              If session tracking is already in progress, pause it.
                        Otherwise, resume tracking or create a new session in
                        the current directory.

:Obsess!             Stop obsessive and delete the underlying session file.

:ObsessRestore       Restore an existing session for the current project root

Loading a session created with |:Obsess| automatically resumes updates to
that file.

========================================================================
BINDINGS                                               *obsessive-bindings*

Default keybindings

* Restore session >
  nnoremap <leader>sr :ObsessRestore<CR>
